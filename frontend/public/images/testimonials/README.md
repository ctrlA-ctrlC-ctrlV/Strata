# Testimonial Images

This directory contains customer testimonial photos.

## Image Requirements
- Format: WebP (with JPEG fallback)
- Dimensions: 150x150 (1:1 aspect ratio, square)
- Quality: 90% compression
- Alt text: Must describe the person or be empty if decorative

## Naming Convention
- customer-001.webp / customer-001.jpg
- customer-002.webp / customer-002.jpg
- etc.

## Privacy Notice
Ensure all testimonial images have proper consent for usage.
