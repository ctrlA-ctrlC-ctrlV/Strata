# Logo Images

This directory contains company logos and brand assets.

## Image Requirements
- Format: SVG (preferred) or PNG with transparency
- Dimensions: Multiple sizes for responsive usage
- Quality: Vector or 100% for PNG
- Alt text: Company name or "Company logo"

## Naming Convention
- strata-logo.svg
- strata-logo-white.svg
- strata-logo-192.png
- strata-logo-512.png
- partner-logos/ (subdirectory for partner/certification logos)
