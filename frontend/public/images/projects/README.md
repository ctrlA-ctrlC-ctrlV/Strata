# Project Images

This directory contains specific project images for product sections.

## Image Requirements
- Format: WebP (with JPEG fallback)
- Dimensions: 800x600 (4:3 aspect ratio)
- Quality: 85% compression
- Alt text: Must describe the project type and location

## Naming Convention
- garden-room-example.webp / garden-room-example.jpg
- home-extension-example.webp / home-extension-example.jpg
