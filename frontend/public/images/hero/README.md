# Hero Images

This directory contains hero section images for the landing page.

## Image Requirements
- Format: WebP (with JPEG fallback)
- Dimensions: 1920x1080 (16:9 aspect ratio)
- Quality: 85% compression
- Alt text: Must be descriptive for accessibility

## Naming Convention
- hero-main.webp / hero-main.jpg
- hero-secondary.webp / hero-secondary.jpg
